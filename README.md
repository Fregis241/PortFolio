# Portfolio · Fregis Omanda

Portfolio personnel : identités de marque, supports imprimés, interfaces web.
Arche, agence de communication 360.

En ligne : https://fregis241.github.io/PortFolio/

## Contenu du dépôt

| Chemin | Rôle |
| --- | --- |
| `index.html` | Le portfolio, export autonome du projet Claude Design |
| `assets/` | Visuels du portfolio (branding, flyers, interfaces) |
| `imgs/` | Images de la version précédente, encore appelées par URL absolue |
| `source/` | Documents de travail `.dc.html` et instructions du projet |
| `2024/` | Version précédente du portfolio, conservée et consultable |

La version 2024 reste en ligne à https://fregis241.github.io/PortFolio/2024/
et sur la branche `portfolio-2024`.

## Direction artistique

- Police : Montserrat, graisses 200 / 300 / 400 / 700 / 800
- Accent : argent et chrome, dégradés du blanc au gris. Pas de doré.
- Pas de tirets cadratins ni demi-cadratins dans les textes visibles.

## Mise en ligne

GitHub Pages sert la branche `main` à la racine. Un `git push` suffit,
le site se met à jour en une à deux minutes.
